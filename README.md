# Automação de Testes de Software

Repositório destinado aos exercícios, atividades e projetos desenvolvidos na disciplina de **Automação de Testes de Software**.

## 📚 Sobre a disciplina

A disciplina aborda conceitos e práticas relacionados à automação de testes, buscando aplicar técnicas e ferramentas para garantir a qualidade, confiabilidade e manutenção de sistemas de software.

## 🎯 Objetivo do repositório

Este repositório tem como objetivo organizar as atividades práticas desenvolvidas durante a disciplina, incluindo exercícios, exemplos e projetos relacionados à automação de testes.

## 🧪 Conteúdos

Entre os principais conteúdos trabalhados estão:

* Fundamentos de testes de software
* Testes automatizados
* Testes unitários
* Testes de integração
* Testes funcionais
* Testes de API
* Frameworks e ferramentas de automação
* Boas práticas para criação de testes
* Execução e análise de testes
* Relatórios de testes
* Integração dos testes ao desenvolvimento de software

## 🛠️ Tecnologias e ferramentas

As tecnologias utilizadas poderão variar de acordo com cada atividade.

* Python
* Pytest
* Selenium
* FastAPI
* Git e GitHub
* Outras ferramentas utilizadas durante a disciplina
